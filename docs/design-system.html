Design System — "Warm & Craft"

A terracotta-and-cream palette chosen to read as hospitality-specific, not generic-SaaS-blue. This documentation site uses the same tokens.

Why this direction

The original UI used the default Tailwind blue (#2563eb) that ships unstyled on countless templates — flat white cards, thin gray borders, system font for everything including headline numbers, an unstyled default chart. None of that is broken, but none of it signals "professional paid product" either, which matters commercially for something asking restaurant owners to trust it with their payments. Three directions were sketched (Warm & Craft, Bold Modern SaaS, Dark-first Pro) and this one was chosen.

Functional colors (success/warning/danger) kept close to convention so they stay instantly legible — success #15803d, warning #b45309 (already warm, fit naturally), danger #dc2626.

Typography

Outfit (Google Fonts, loaded via @import) for display contexts only — page headings, the brand logo, stat-card numbers, cart totals. Everything else (body copy, tables, forms, badges) stays on the system font stack for legibility and information density. Two-tier on purpose: personality where it's most visible, maximum readability where data lives.

Where the tokens live

FileScope
frontend/css/style.cssStaff app — defines the base :root tokens
frontend/site/css/site.cssCustomer site — @imports the staff stylesheet, then overrides --primary/--bg/etc. to the same terracotta family (previously an unrelated maroon/gold palette)
docs/assets/docs.cssThis documentation site

Because both frontends share one token set via CSS custom properties, a palette change cascades through every shared component (.card, .btn, .navbar, tables, forms) automatically — no need to hand-edit dozens of individual pages.

Component patterns

Cards

Rounded (14px), soft shadow instead of a flat border-only look, warm-white background slightly off from pure white.

Stat cards

A 4px terracotta left-accent bar on every stat card, Outfit font for the number itself.

Charts

Chart.js bars use a terracotta-to-orange gradient fill with rounded tops, warm-toned gridlines instead of default gray.

Navigation

Both navbars (staff app, customer site) use the same near-black warm espresso (#241811), not the generic cool slate they started with.

PWA assets

App icons (frontend/site/icons/icon-*.svg), the manifest's theme_color/background_color, and the theme-color meta tag on all 12 customer-site pages were updated to match — so the installed home-screen icon and mobile browser chrome tint correctly too, not just in-page colors.
