DokanPro

A multi-tenant restaurant & retail management platform — point of sale, online ordering, reservations, and staff operations, built to be sold as SaaS to independent restaurants.

DokanPro started as a single-store retail POS system and grew into a full restaurant platform: online ordering with Stripe payments, table reservations, a kitchen display, loyalty points, and — as of the most recent work — genuine multi-tenancy, so many independent restaurants can run on one deployment, each fully isolated from the others, each with their own Stripe account for payments and their own subscription to the platform.

At a glance

BackendFastAPI + SQLAlchemy 2.0 + PostgreSQL, Alembic migrations
FrontendVanilla JS/HTML/CSS — no build step, no framework
Deployment unitTwo Docker Compose services (backend + db); one process serves API and frontend together
Tenancy modelShared database, row-level isolation via business_id, enforced by a global SQLAlchemy query filter
PaymentsStripe Connect (Standard accounts) for diner payments, Stripe Subscriptions for platform billing
Two frontendsStaff app (POS, inventory, orders, admin) and a separate customer-facing ordering site, per tenant
